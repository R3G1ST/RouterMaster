RouterMaster

Умный помощник по настройке роутеров на OpenWrt

1. Введите данные роутера на вкладке «Подключение»
2. Выберите шаги на вкладке «Что выполнить»
3. Настройте Wi-Fi и прокси на вкладке «Параметры»
4. Нажмите «ВЫПОЛНИТЬ» — результат будет виден в окне лога
